# li-thuyet-do-thi

Ứng dụng học lý thuyết đồ thị xây bằng React + Vite, tập trung trực quan hóa các thuật toán:

- BFS, DFS
- Dijkstra
- Prim, Kruskal
- Eulerian check
- Bipartite check

## Giao diện

- **Sidebar trái**: nhập danh sách cạnh, chọn thuật toán, đỉnh bắt đầu và kiểu đồ thị.
- **Canvas giữa**: hiển thị đồ thị, cạnh/trọng số, các đỉnh/cạnh được tô sáng theo kết quả.
- **Sidebar phải**: mô tả thuật toán và kết quả chi tiết sau khi chạy.

## Chạy dự án

```bash
npm install
npm run dev
```

## Kiểm tra chất lượng
